Gradients along paths

Backpropagation is the chain rule applied to a computation graph. This page checks one move: multiply local derivatives along each path from a quantity to the loss, and add the contributions of different paths.

About 3 minutes if you remember it. About 10 if you use the reminder.

Start with the task below. If you get it right, you are done.

The rules you need

  • A local derivative is one node's derivative with respect to a node feeding it, at the forward-pass values: here ∂q/∂b = a, ∂s/∂q = 1, ∂s/∂b = 1 and ∂L/∂s = 2s.
  • Along one path, local derivatives multiply.
  • When a quantity reaches the loss along several paths, the contributions add.
