# Deep Learning optional reviews

Ungraded activities that run in the browser, with reminders and practice that unfolds as you work. No programming is needed, and nothing is recorded. Each link opens the page on GitHub Pages.

## Math refreshers

Each refresher checks one piece of mathematics that the problem sets use, then offers a reminder if you need it. The second column lists the problem sets that use it. Course codes are shortened: 1x is `6.7960.1x`.

| Math refresher | Used in | What you practice |
| --- | --- | --- |
| [Vectors and matrices](https://codey-m.github.io/deep_learning/practice/vectors_matrices/) | 1x Problem Sets 1 and 2; 3x Problem Set 2; 4x Problem Set 1 | Compute each entry of a matrix–vector product and track the shapes of a product. |
| [Gradients along paths](https://codey-m.github.io/deep_learning/practice/gradient_paths/) | 2x Problem Set 1 | Multiply local derivatives along each path to the loss, and add over paths. |
| [Logs and exponentials](https://codey-m.github.io/deep_learning/practice/logs_exponentials/) | 3x Problem Set 2; 4x Problem Set 2; 5x Problem Sets 1 and 2 | Get the exponential on its own, then take the log of both sides. |
| [Projection onto a direction](https://codey-m.github.io/deep_learning/practice/projection/) | 4x Problem Set 1 | Encode with a dot product, decode, and measure what is left over. |
