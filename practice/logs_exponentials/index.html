Logs and exponentials

Later problem sets ask you to undo an exponential or simplify a log, for example to solve a loss for the value that reaches a target. This page checks one move: get the exponential on its own, then take the log of both sides.

The rules you need

  • ln and e undo each other: ln(eu) = u, and eln c = c for c > 0.
  • ln(ab) = ln a + ln b, ln(a/b) = ln a − ln b, and ln(1/a) = −ln a.
  • ln(ak) = k ln a.
  • ea+b = eaeb and ea−b = ea/eb.
  • ln is increasing: a larger positive number has a larger log. There is no rule for ln(a + b).

    Show the full worked explanation
    1. Undo the − 1 by adding 1 to both sides: 3e−2t = 6.
    2. Undo the 3 by dividing both sides by 3: e−2t = 2. The exponential now stands alone.
    3. Take ln of both sides. Since ln(eu) = u, the left side becomes the exponent: −2t = ln 2.
    4. Divide by −2: t = −ln(2)/2 ≈ −0.347.

    A quick check: e−2t = eln 2 = 2, and 3 × 2 − 1 = 5.

    The order matters. Taking ln before the exponential stands alone would leave ln(3e−2t − 1), which no rule simplifies.
