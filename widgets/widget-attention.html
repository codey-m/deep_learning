Scaled dot-product attention

One query attends to five keys. Set each raw score (the query·key match), then change the dimension d to see the √d scaling reshape the weights.

d = 4,   √d = 2.00
keyraw scorescore/√dattention weightvalue
Weights are softmax(score / √d) and always sum to 1.00.
Attention output = Σ weight × value = 0.00.

What this sweep holds fixed: only the divisor changes; all five raw scores stay fixed. Under that condition, larger d flattens the weights. In a real head, unscaled query-key dot-product variance typically grows with dimension; dividing by √d counteracts that growth.
