How a deep network turns a loss into an update

How does a network turn a loss into an update, and what keeps that update useful in a deep stack?

1 · Clip

Gradient clipping

Each step moves the parameters by −η∇J, where η is the learning rate.

Where the loss is steep, ∇J is large, and so is the step.

Clipping limits each component of the gradient to ±m before the step.

2 · Backprop

Backpropagation

Each layer computes Wx + b, with parameters θ = (W, b).

The loss J is one number at the end of the chain.

Going back, each layer receives g, the gradient of J with respect to its output, written as a row.

What changed

One backward pass gives every layer its gradients. On the way back each layer multiplies g by its W, so the g that reaches an early layer is a product of every W after it.

3 · Initialize

Initialization

Going back, each layer multiplies g by its W.

So the starting weights decide how big g is when it reaches the first layer.

This stack has 20 layers of n = 256 inputs. You choose Var(W), the variance the starting weights are drawn with.

One layer up close

Xavier initialization

With linear layers, each layer multiplies g's variance by n · Var(W). Var(W) = 1/n makes that multiplier 1, so g keeps its size all the way back.

Kaiming initialization

At the linear setting, ReLU cuts the expected gradient variance roughly in half at each layer: about half the units are off, and they pass no gradient back. After 20 layers, about of the starting variance remains. Var(W) = 2/n doubles each layer's multiplier back to about 1.

In the opener the multiplier was a slider. Here it is n · Var(W), and ReLU halves it.

What changed

Both methods choose the starting variance so that each layer's multiplier is about 1, and the right choice depends on the activation. The lecture follows the signal forward; here we follow the gradient backward. Both give the same ½ in this equal-width network.

4 · Normalize

Normalization

One learning rate has to suit every weight, so inputs are put on a common scale.

Each layer's activations are the next layer's input, and their scale drifts as training proceeds.

A normalization layer subtracts a mean and divides by a standard deviation, then rescales.

What changed

Both normalize the same way; they differ in the axes they average over. Batch norm averages over images and locations for one channel; layer norm averages over channels for one image and location.

5 · Shortcut

Residual connections

Past about 20 to 30 layers, a deeper plain network does worse, even on its training data.

A deeper network could copy a shallower one if its extra layers passed their input straight through.

What changed

When the residual branch contributes zero, the block passes its input through unchanged, so a block that is not needed only has to learn F(x) = 0. On the backward pass, the shortcut also gives the gradient a direct path to the earlier block.

Across the page: backprop supplies the gradient, clipping limits each step, initialization sets the gradient's starting scale, normalization keeps inputs on scale, and shortcuts let added depth start from doing nothing.
